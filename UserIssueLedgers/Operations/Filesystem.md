# User Issue Ledger: Operations / filesystem

| ID | Applies to | Mistake pattern | Required behavior | Prevention and verification |
| --- | --- | --- | --- | --- |
| UIL-OPERATIONS-FILESYSTEM-001 | Repository ownership, modes, groups, ACLs, and hard-linked dependency trees on the shared development machine | Treating the owner's local Unix accounts as separate repository security principals, accumulating per-user ACL exceptions, or recursively changing repository inode metadata without checking whether hard-link aliases exist outside the repository | Give every participating account the same repository rights through one shared group; keep repository ACLs simple; do not mutate external cache aliases; keep per-user privacy only for runtime data such as credentials and usage databases | Before changing repository permissions, apply `security-assumptions.md`; inventory physical symlinks, mounts, and hard-link aliases outside the checkout; isolate in-repository dependency copies before metadata changes; use equal owner/group `rwX`, shared-group inheritance on directories, and no named user ACLs; then verify group, modes, default ACLs, absence of unrelated access, zero external-linked repository inodes, and cross-user create/edit/delete behavior |
